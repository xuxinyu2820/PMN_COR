This folder contains the code for the FIRE-Swap structural optimization of PMN.

The folder `01.initial_configs` contains the initial 6X6X6 (homogeneous disorder) and 12X12X12 (random-layer model) configurations of PMN.

The folder `02.6X6X6` contains the code for the FIRE-Swap structural optimization of PMN with 6X6X6 initial configurations.

The folder `03.12X12X12` contains the code for the FIRE-Swap structural optimization of PMN with 12X12X12 initial configurations.

The folder `04.Cluster_Analysis` contains the code for the cluster analysis of the optimized structures.
